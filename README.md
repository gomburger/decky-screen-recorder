# Screen Recorder

SteamOS 게임 모드 화면을 빠른 메뉴(Quick Access, `…` 버튼)에서 녹화하는 Decky Loader 플러그인입니다. 게임뿐 아니라 Steam UI와 빠른 메뉴, MangoHud와 알림까지 녹화할 수 있습니다.

## 필요한 것

- 게임 모드로 실행 중인 SteamOS 기기 (Steam Deck에서 확인했습니다)
- [Decky Loader](https://decky.xyz/)

## 설치

1. [릴리스 페이지](https://github.com/gomburger/decky-screen-recorder/releases/latest)에서 `decky-screen-recorder-<version>.zip`을 Steam Deck에 내려받습니다.
2. Decky 설정에서 개발자 모드를 켭니다.
3. Decky 설정의 **개발자** 메뉴에서 **ZIP으로 플러그인 설치**를 선택하고 내려받은 파일을 고릅니다.

업데이트도 같은 방법으로 설치하면 됩니다. 설정은 유지됩니다.

## 빠른 시작

1. 빠른 메뉴에서 **Decky → Screen Recorder**를 엽니다.
2. **녹화 시작**을 누릅니다. 녹화 카드에 경과 시간이 표시됩니다.
3. 다시 빠른 메뉴를 열고 **중지하고 저장**을 누릅니다.
4. 녹화는 `~/Videos/ScreenRecorder`에 `Recording_날짜시간_방식.mp4`로 저장됩니다.

## 캡처 방식

**캡처 방식** 드롭다운에서 고릅니다. 기본은 PipeWire입니다.

| 방식 | 녹화 범위 | 참고 |
|---|---|---|
| **PipeWire** | 게임, Steam UI, 빠른 메뉴, 알림 | 녹화를 끝낼 때 드물게 gamescope가 충돌할 수 있습니다. 실제 사용 테스트에서는 발생하지 않았습니다. |
| **KMS** | 화면 전체 (MangoHud 포함) | 녹화하는 동안 gamescope 강제 합성을 켭니다. |

## 설정

**원본 색으로 녹화** (KMS, 기본 켜짐): 녹화하는 동안만 무라 보정, 채도, 색온도, 야간 모드를 원래대로 돌려 게임의 원래 색으로 녹화하고, 끝나면 되돌립니다. 채도는 연결된 화면의 색역에 맞춰 바꿉니다. 녹화하는 동안 화면 색이 달라 보일 수 있습니다. 화면에 따라 적용할 수 없으면 옵션이 보이지 않습니다.

**화질** (기본 높음): Steam 게임 녹화와 같은 프리셋(가장 높음, 높음, 중간, 낮음)을 씁니다. **직접 설정**을 고르면 해상도와 관계없이 2–50 Mbps 중에서 비트레이트를 정합니다.

**프레임 레이트** (기본 60 FPS): 30 FPS로 낮추면 녹화 부담이 줄어듭니다. 해상도는 화면을 따릅니다.

**마이크 녹음** (기본 꺼짐): 기본 입력 장치를 함께 녹음합니다.

- **모노로 녹음** (기본 켜짐): 마이크 채널을 하나로 합쳐 양쪽에서 똑같이 들리게 합니다.
- **별도 트랙으로 저장** (기본 꺼짐): 게임 소리와 섞지 않고 두 번째 오디오 트랙으로 저장합니다.

**저장 위치 변경**: microSD 카드 같은 다른 폴더를 고릅니다. **기본 위치로 되돌리기**로 `~/Videos/ScreenRecorder`로 돌아갑니다.

## HDR

PipeWire는 gamescope가 SDR로 바꾼 화면을 그대로 녹화합니다. KMS로 HDR 화면을 녹화하면 플러그인이 SDR로 변환해 저장합니다.

- **Steam Deck OLED 내부 화면, 외부 HDR 모니터**: PipeWire 녹화(gamescope의 SDR 변환)와 같은 밝기와 색이 되도록 맞췄습니다.
- **다른 기기의 내부 HDR 화면**: 측정값이 없어 보정 없이 변환합니다. 녹화 카드에 "보정 없음"으로 표시됩니다.
- **외부 모니터에서 HDR을 켜 둔 경우**: HDR 게임이 아니어도 화면 전체가 HDR 신호로 출력됩니다. 이때는 SDR 게임과 Steam 화면도 원래의 SDR 색으로 되돌려 녹화합니다. 녹화 카드에 "외부 HDR 화면"으로 표시됩니다.

## 문제 해결

| 증상 | 해 볼 것 |
|---|---|
| "KMS 캡처가 이 화면의 영상을 받지 못했습니다" | 캡처 방식을 **PipeWire**로 바꿔 녹화합니다. |
| "그 폴더에는 저장할 수 없습니다" 또는 녹화가 시작되지 않음 | microSD 카드가 꽂혀 있는지 확인하거나 **기본 위치로 되돌리기**를 누릅니다. |
| PipeWire 녹화를 끝낼 때 게임과 Steam이 꺼짐 | 캡처 방식을 **KMS**로 바꿉니다. |
| PipeWire 녹화에 MangoHud가 안 나옴 | PipeWire는 MangoHud를 녹화하지 않습니다. **KMS**를 씁니다. |
| KMS 녹화 색이 화면에서 본 것과 다름 | **원본 색으로 녹화**를 켜면 화면 설정(채도, 색온도, 야간 모드 등)을 뺀 게임의 원래 색으로 녹화하므로, 패널 특성에 따라 화면과 다르게 보일 수 있습니다. 화면 설정까지 녹화하려면 이 옵션을 끕니다. |
| "녹화가 예기치 않게 중단되었습니다" | gamescope가 다시 시작되는 등 캡처가 도중에 끊긴 경우입니다. 그때까지 녹화된 부분은 저장되어 있습니다. |
| 녹화 중 플러그인이나 Decky가 꺼짐 | 다음에 플러그인이 시작될 때 화면 설정을 되돌리고, 남은 녹화를 `Recording_날짜시간_recovered.mp4`로 저장합니다. |

## 알려진 제한

- KMS로 HDR을 녹화할 때는 RADV의 실험 기능인 Vulkan H.264 인코더를 사용합니다. SteamOS 업데이트로 동작이 달라질 수 있습니다.
- Steam Deck OLED(SteamOS 3.9)와 외부 모니터 몇 대에서 확인했습니다. 다른 기기와 화면에서는 동작이 다를 수 있습니다.
- KMS 녹화 중에는 gamescope 강제 합성 때문에 성능이 조금 떨어질 수 있습니다.

## 작동 방식과 개인정보

SteamOS에 포함된 ffmpeg와 GStreamer로 녹화합니다. 영상과 소리는 별도 프로세스로 녹화한 뒤 하나의 MP4로 합칩니다. KMS 캡처에 root 권한이 필요해 플러그인이 root로 실행되며, 소리와 마이크 녹음, PipeWire 캡처, 파일 합치기는 일반 사용자 권한으로 실행합니다.

녹화 파일은 이 기기의 저장 위치에만 저장하고 외부로 보내지 않습니다.
